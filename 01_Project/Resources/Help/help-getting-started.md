# Getting Started

LLM Usage Status shows usage for three command-line tools in one floating panel: Codex, Claude Code and Mistral Vibe.

## No Dock icon

The app has no Dock icon and no regular window. It runs in the background and waits for its shortcut.

## Show and hide the panel

Press **Control-Option-Command-L** from any app to show the panel. Press it again to hide it. You can change this shortcut in Settings (see Settings and Shortcuts). The header of the panel always shows your current shortcut.

Click anywhere outside the panel to dismiss it. Drag the panel to move it.

## Refreshing

Usage refreshes each time you open the panel. Each provider refreshes on its own, so one slow or failing provider never blocks the others. While the panel is open, a countdown also triggers a refresh when a reset time passes.

## Right-click menu

Right-click the panel for **Show 5-hour limit**, **Set Vibe Monthly Budget…**, **Settings…**, **LLM Usage Status Help**, **Restart LLM Usage Status**, **Send Feedback…**, **Leave a Tip** and **Quit LLM Usage Status**.

## Expand a section

Click a section to expand or collapse its details. Hover over it for a short summary.
